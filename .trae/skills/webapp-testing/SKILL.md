# Web App Testing

This skill enables automated web application testing using Playwright:

- Generating automated test scripts
- Executing browser automation tests
- Verifying frontend functionality
- Debugging interface issues
- Analyzing page behavior

## When to Invoke

Invoke this skill when:
- User needs to test web application functionality
- User wants to automate browser testing
- User needs to verify frontend features work correctly
- User is debugging interface or page behavior issues
- User wants to create comprehensive test suites

## Features

- **Test Script Generation**: Creates automated test scripts using Playwright
- **Test Execution**: Runs automated tests across different browsers
- **Functionality Verification**: Verifies frontend features and interactions
- **Interface Debugging**: Helps debug UI issues and layout problems
- **Behavior Analysis**: Analyzes page behavior and interactions
- **Cross-browser Testing**: Tests across Chrome, Firefox, Safari, and Edge

## Testing Capabilities

- Page navigation and routing
- Form filling and submission
- User interaction simulation
- API response verification
- Error handling validation
- Performance measurement
- Screenshot and video capture

## Usage Examples

- "Create a Playwright test for this login page"
- "Verify the checkout flow works correctly"
- "Debug why this button click is not working"
- "Run automated tests on my web application"
- "Analyze the behavior of this interactive component"

## Output Format

The skill will provide:
- Generated Playwright test scripts
- Test execution results
- Bug reports and debugging information
- Screenshot evidence (if applicable)
- Performance metrics
- Recommendations for fixes
