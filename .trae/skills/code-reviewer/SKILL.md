# Code Reviewer

This skill reviews code and provides feedback on:

- Code quality and best practices
- Potential bugs and issues
- Performance optimization
- Security vulnerabilities
- Code style and consistency
- Maintainability and readability
- Architecture and design patterns

## When to Invoke

Invoke this skill when:
- User needs to review code before deployment
- User wants to improve code quality
- User is experiencing issues with their code
- User needs to ensure code follows best practices
- User wants to identify potential security vulnerabilities

## Supported Technologies

- Java
- JavaScript/TypeScript
- Python
- C++
- Go
- Ruby
- PHP
- And other common programming languages

## Review Process

1. Analyze code structure and organization
2. Check for syntax errors and bugs
3. Review security practices
4. Evaluate performance implications
5. Assess code style and consistency
6. Provide actionable recommendations
7. Suggest improvements for maintainability

## Output Format

The review will include:
- Summary of findings
- Detailed feedback on specific issues
- Code examples for improvements
- Priority levels for each recommendation
- Best practices to follow
- Suggested refactoring approaches
