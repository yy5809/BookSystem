# Frontend Code Review

This skill reviews frontend code and provides feedback on:

- Code quality and best practices
- Performance optimization
- Security vulnerabilities
- Accessibility issues
- Cross-browser compatibility
- Code style and consistency
- Architecture and design patterns

## When to Invoke

Invoke this skill when:
- User needs to review frontend code before deployment
- User wants to improve frontend code quality
- User is experiencing frontend performance issues
- User needs to ensure frontend code follows best practices
- User wants to identify potential security vulnerabilities in frontend code

## Supported Technologies

- HTML5
- CSS3/SCSS/LESS
- JavaScript/TypeScript
- Vue.js/React/Angular
- Frontend build tools (Webpack, Vite, etc.)
- Responsive design
- Accessibility standards (WCAG)

## Review Process

1. Analyze code structure and organization
2. Check for performance bottlenecks
3. Review security practices
4. Verify accessibility compliance
5. Evaluate code style and consistency
6. Provide actionable recommendations
7. Suggest improvements for maintainability

## Output Format

The review will include:
- Summary of findings
- Detailed feedback on specific issues
- Code examples for improvements
- Priority levels for each recommendation
- Best practices to follow
