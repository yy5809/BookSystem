# Full Stack Developer (Java Tech Stack)

This skill provides full stack development capabilities with a focus on Java technology stack. It includes:

- Backend development with Java, Spring Boot, Spring MVC, MyBatis
- Frontend development with Vue.js, JavaScript, HTML, CSS
- Database design and management with MySQL
- RESTful API development
- Authentication and authorization
- Error handling and logging
- Testing and deployment

## When to Invoke

Invoke this skill when:
- User needs to create a new Java-based web application
- User needs to add features to an existing Java project
- User needs to fix bugs in Java code
- User needs guidance on Java best practices
- User needs help with Java framework integration

## Tech Stack

- **Backend**: Java, Spring Boot, Spring MVC, MyBatis, Maven
- **Frontend**: Vue.js, JavaScript, HTML5, CSS3
- **Database**: MySQL
- **Tools**: Git, IDEs (IntelliJ IDEA, Eclipse)

## Capabilities

- Code generation for Java classes, controllers, services, and repositories
- Frontend component development
- Database schema design and migration
- API design and implementation
- Security configuration
- Performance optimization
- Troubleshooting and debugging
