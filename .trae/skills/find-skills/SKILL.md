# Find Skills

This skill helps users find and discover available skills for their workspace. It includes:

- Listing all available skills
- Searching for skills by name or description
- Filtering skills by category or functionality
- Providing details about each skill
- Recommending relevant skills based on user needs

## When to Invoke

Invoke this skill when:
- User wants to see all available skills
- User needs to find a specific skill for a task
- User is looking for skills related to a particular domain
- User wants to explore new skills to add to their workspace
- User needs help understanding what skills are available

## Capabilities

- List all installed skills with brief descriptions
- Search skills by keywords
- Filter skills by category (e.g., development, testing, design)
- Provide detailed information about specific skills
- Recommend skills based on user context
- Suggest skill combinations for complex tasks

## Usage Examples

- "Find all skills related to code review"
- "List all available skills in my workspace"
- "What skills can help with web development?"
- "Find a skill for testing web applications"
- "Show me details about the code-reviewer skill"

## Output Format

The skill will provide:
- A comprehensive list of available skills
- Brief descriptions of each skill
- Categories or tags for easy filtering
- Detailed information when requested
- Actionable recommendations for skill usage
