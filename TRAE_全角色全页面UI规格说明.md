### 库存状态标签样式

```
正常  →  <el-tag type="success" size="small">正常</el-tag>    绿色

```

库存状态为"缺货"时，整行背景色变为浅红 `background-color: #fef0f0`

### 操作按钮动态显示规则

| 采购单状态 | 显示的按钮 | 隐藏的按钮 |

| 已入库(3) | 查看明细 | 编辑、删除、推进状态、确认到货、确认入库 |

# 第四部分：全局交互规范

## 4.1 统一弹窗规范

| 项目 | 规范 |
|---|---|
| 弹窗宽度 | 小弹窗 420px / 中弹窗 500px / 大弹窗 600px / 超大弹窗 700~800px |
| 弹窗居中 | `:close-on-click-modal="false"` 防止误关 |
| 按钮位置 | 右下角，[取消] 在左，[确认] 在右 |
| 确认按钮 | 主色 `type="primary"`，危险操作用 `type="danger"` |
| 表单校验 | 必填字段标红星，blur 触发校验 |
| 加载状态 | 提交后按钮显示 loading，防止重复提交 |

## 4.2 统一表格规范

| 项目 | 规范 |
|---|---|
| 斑马纹 | `stripe` |
| 边框 | `border` |
| 序号列 | `type="index"`，宽度 60 |
| 长文本 | `show-overflow-tooltip` |
| 空数据 | 显示"暂无数据" |
| 加载状态 | `v-loading` 指令 |

## 4.3 统一标签颜色规范

| 状态 | el-tag type | 颜色 |
|---|---|---|
| 正常/成功/已通过/已出库/已完成 | success | 绿色 |
| 预警/采购中/领取中/部分出库/紧急 | warning | 橙色 |
| 缺货/已驳回/特急 | danger | 红色 |
| 草稿/已入库/已取消/普通 | info | 灰色 |
| 待审核/待采购/已发布/已到货 | 默认（无 type） | 蓝色 |

## 4.4 统一确认弹窗规范

```
删除操作：
  $confirm('确定要删除该记录吗？', '提示', { type: 'warning' })

危险操作（出库/入库）：
  $confirm('确认执行该操作？此操作不可撤销。', '提示', { type: 'warning' })

批量操作：
  $confirm(`确定要删除选中的 ${selected.length} 条记录吗？`, '提示', { type: 'warning' })
```

## 4.5 消息提示规范

```
操作成功：this.$message.success('操作成功')
操作失败：this.$message.error('操作失败：' + error.message)
校验失败：this.$message.warning('请填写完整信息')
提示信息：this.$message.info('提示内容')
```
