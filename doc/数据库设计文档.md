## 2. 数据库设计原则

- 所有业务表统一采用 `InnoDB` 存储引擎，支持事务和外键约束
- 字符集统一使用 `utf8mb4`，支持完整的 Unicode 字符（包括 emoji）
- 主键统一使用 `bigint AUTO_INCREMENT` 自增策略
- 统一添加 `del_flag` 字段支持软删除（0=存在，2=删除）
- 统一添加审计字段：`create_by`、`create_time`、`update_by`、`update_time`
- 关键业务字段添加索引以提高查询效率

## 6. 实体关系说明

### 6.1 核心实体关系

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│textbook_info│────<│textbook_stock│────<│stock_flow │
│   教材信息   │     │    库存     │     │  库存流水   │
└─────────────┘     └─────────────┘     └─────────────┘
       │
       ├──────┬───────┬───────┬───────┐
       │      │       │       │       │
       ▼      ▼       ▼       ▼       ▼
   ┌─────┐┌─────┐┌─────┐┌─────┐┌──────┐
   │入库  ││出库  ││采购  ││缺书  ││个人申请│
   └─────┘└─────┘└─────┘└─────┘└──────┘
```

### 6.2 业务模块流转

```
领书通知发布 → 领书单创建 → 出库操作 → 库存扣减
     │
     └→ 缺书登记 → 待购处理 → 采购下单 → 入库操作 → 库存增加
```
